# Listing 输出模板（13 段，顺序固定）

> 用法：复制本骨架，逐段填充。每段前面的「要求」来自 `references/01-listing-spec.md`，填完删掉要求行。
> 交付前把全文存成 `{ASIN}_文案数据_{日期}.json` 跑 `scripts/check_listing.py`。

---

## 1. 关键词表（含分配去向）

```
核心词：
长尾词：
属性词：
场景词：
人群词：
同义词：
替代方案词：

分配：
Title ←
Item Highlights ←
五点 ←
描述 ←
Search Terms ←
```

要求：七类齐全；逐词标去向；核心词 100%、长尾 ≥80% 覆盖；Title 与 Highlights 零重复词；Highlights 与 ST 零重复。

---

## 2. 产品定位分析（中文）

- 产品类型：
- 目标买家：
- 目标国家主要使用场景：
- 买家核心需求：
- 买家主要痛点：
- 下单前主要顾虑：
- 产品核心优势：
- 建议主推关键词：
- 建议避免的风险词 / 未证实表达：

要求：简洁，不写成长篇市场报告。

---

## 3. Title

```
Title:
Character Count:
```

要求：≤75 字符（含空格标点）；只用分配给 Title 的核心词+属性词；无品牌名/促销词/特殊符号；Title Case 介词小写；变体属性不进标题。

---

## 4. Item Highlights

```
Item Highlights:
Character Count:
```

要求：≤125 字符；4-6 个词组，逗号分隔；补充标题未覆盖的材质/场景/对象/次要用途；与 Title 零重复词；与 ST 零重复。

---

## 5. 五点描述

```
【卖点标题】正文
【卖点标题】正文
【卖点标题】正文
【卖点标题】正文
【卖点标题】正文
```

要求：每条一个卖点，互不重复；Title Case 标题；1-2 句；先好处后依据；每条埋 1-2 个分配来的长尾/场景词；满足自然度三条标准；按「核心问题→功能好处→材质耐用→便利性→适用场景」排序。

---

## 6. HTML Product Description

```
HTML Product Description:
<p>…</p>
<p>…</p>
<p>…</p>
```

要求：仅 `p/b/br/ul/li`；无 CSS/JS/图片/链接/颜色/字号；2-3 段；正文 600-800 字符；不加代码框、不加说明。

---

## 7. Plain Text Product Description

```
Plain Text Product Description:
段落一…

段落二…

段落三…
```

要求：无标签、段间空行、与 HTML 版信息完全一致、600-800 字符。

---

## 8. Search Terms

```
Search Terms:
```

要求：≤250 字节；无逗号标点；只放前台未覆盖的词；单词不重复；无品牌/ASIN/无关流量词。

---

## 9. 图片规范建议（中文）

```
图片规范建议：
主图：（纯白 RGB 255,255,255 / 产品占比 ≥85% / 最短边 ≥1000px / 无文字水印 / 完整不裁切）
副图1：（类型 + 要传达的信息 + 视觉作用）
副图2：
副图3：
副图4：
副图5：
副图6：
```

要求：主图硬指标写全；副图最多 6 张，按产品特性从六类里选；每张说明「说服买家什么」。

---

## 10. A+ Content 建议（中文）

```
A+ Content 建议：
模块1：[类型] - [内容建议]
模块2：[类型] - [内容建议]
模块3：[类型] - [内容建议]
模块4：[类型] - [内容建议]
模块5：[类型] - [内容建议]
```

要求：模块从「品牌故事卡 / 对比表（≤4 行）/ 使用场景大图 / 功能图解 / FAQ 3-5 条」里选；与 Listing 参数一致；与第 9 节图片建议衔接不重复拍摄；未做品牌注册则整段写「跳过（未完成品牌注册）」。

---

## 11. 中文翻译

```
Title（中文）：
Item Highlights（中文）：
五点（中文）：
产品描述（中文）：
```

要求：按非 HTML 版翻译一份；准确表意，不逐词硬译；不得增加原文没有的卖点。

---

