# Amazon Listing 撰写规范（《亚马逊CHATGPT写页面（第四版）》）

> 本文件是规范的完整落地版，结构与原文一致。原文路径：`桌面/亚马逊SKILL第二版/亚马逊CHATGPT写页面(第四版).docx`
> 缺失信息一律标「待确认」，不得猜测补齐 —— 这是规范第一原则。

## 输入开场（填写化模板）

```
请根据我上传的产品图片和提供的产品资料，为该产品撰写一套适用于亚马逊【目标国家/站点】的高转化 Listing。
目标站点：【英国站/德国站/法国站等】
输出语言：【英语/德语/法语等】
产品资料：【填写尺寸、材质、数量、颜色、配件、承重等信息】
```

## 一、产品分析与市场定位

先识别以下信息，再动笔：

- 产品类型、结构、材质、颜色及包装数量
- 产品的主要功能和核心卖点
- 目标买家及其购买动机
- 目标国家买家的主要使用场景
- 产品能够解决的实际问题
- 买家下单前最关注的问题和顾虑
- 相比普通同类产品具有购买价值的特点

结合目标国家买家的生活方式、住宅环境、气候条件、空间大小和使用习惯，选择**最有转化价值**的使用场景。

**卖点撰写逻辑（固定四段式）**：

```
买家需求/痛点 → 产品功能/结构 → 给买家带来的实际好处 → 对应使用场景
```

不要只罗列参数。每个卖点都要说明「解决什么问题」+「带来什么实际价值」。

**真实性红线**：产品图片和资料是唯一依据。不得自行编造尺寸、材质、数量、颜色、承重、防水等级、认证、兼容范围、包装配件或产品性能。关键信息无法确认时，**先列出需要确认的问题**，不要擅自补充。

## 二、关键词策略（必须在写文案前完成）

> 本模块是后续所有文案的输入。先建表并完成分配，再写标题、卖点、描述。

### 2.1 第一步：建立关键词表（七类）

| 类别 | 定义 |
|---|---|
| 核心词 Core | 产品最主流的通用名称，搜索量最大，必须覆盖 |
| 长尾词 Long-tail | 3 个词以上的精准搜索短语，转化意图更强 |
| 属性词 Attribute | 材质、尺寸、颜色、规格、数量等 |
| 场景词 Scenario | 使用场景、使用地点、使用时机 |
| 人群词 Audience | 适用对象或目标人群（避开平台禁用的敏感人群词） |
| 同义词/替代名称 Synonym | 同一产品的其他常见叫法 |
| 替代方案词 Alternative | 买家可能用来搜索替代品的词（不得用竞品品牌名） |

**四条要求**：

1. 所有关键词必须来自目标国家买家的真实搜索表达，不得凭空编造或直译中文。
2. 不得包含品牌名、商标、ASIN、竞品品牌或未经授权的兼容性表达。
3. 不得包含平台禁用的绝对化、无法证明或敏感词。
4. 关键词必须与产品图片和资料一致，不得为凑词加入产品不具备的属性。

**输出格式**：

```
关键词表：
核心词：[词1] | [词2] | [词3]
长尾词：[词1] | [词2] | [词3]
属性词：[词1] | [词2] | [词3]
场景词：[词1] | [词2] | [词3]
人群词：[词1] | [词2]
同义词：[词1] | [词2]
替代方案词：[词1] | [词2]
```

### 2.2 第二步：关键词分配（一个词只主攻一个位置）

标题只有 75 字符，词位极度紧张。必须分配，不是每个模块都塞一遍。

| 位置 | 分配原则 | 词数建议 |
|---|---|---|
| Title | 只放优先级最高的核心词 + 1-2 个关键属性词 | 2-4 个 |
| Item Highlights | 标题未覆盖的次要核心词、材质词、场景词 | 3-5 个 |
| 五点描述 | 每条 1-2 个，以长尾词和场景词为主 | 5-10 个 |
| 产品描述 | 长尾词、场景词、人群词自然融入句子 | 6-10 个 |
| Search Terms | 剩余未覆盖的同义词、替代方案词、拼写变体 | 250 字节内 |

**硬性要求**：

- 同一关键词不得在 Title 与 Item Highlights 中重复出现。
- 同一关键词不得在 5 条卖点中被重复主攻。
- 同一关键词不得同时出现在 Item Highlights 与 Search Terms（Highlights 前台可见，ST 只放前台未覆盖的词）。
- 分配完成后：**核心词 100% 覆盖，长尾词至少 80%**。
- 某核心词因字符限制进不了标题，必须在 Highlights 或五点补上，不能遗漏。

### 2.3 第三步：自然埋词的三条判断标准

「自然融入」是硬性要求，三条必须**同时**满足：

1. 去掉关键词后，句子依然通顺完整。
2. 句子的主语是买家或买家的使用场景，而不是关键词本身。
3. 读起来像正常的当地语言，不像翻译腔，也不像词表。

反例（机械堆砌，禁止）：
`Durable, sturdy, strong, heavy duty, long lasting, premium quality stainless steel measuring cups`
→ 形容词串联，没有句子结构，买家读不到利益点。

正例（自然融入）：
`Clear metric and US markings let you follow any recipe without conversion errors.`

另一组：
- 反例：`Waterproof, anti-slip, easy clean, space saving bathroom shelf`
- 正例：`Rounded edges and a non-slip base keep the shelf steady, even on wet bathroom tiles.`

## 三、文案总体要求

- 符合亚马逊规则，不侵权，不使用竞品品牌、商标、ASIN 或未经授权的兼容性表达。
- 不使用 `Best`、`No.1`、`Perfect`、`Guaranteed`、`100% Safe`、`Never`、`Most Advanced` 等绝对化或无法证明的表达。
- `Waterproof`、`Heavy Duty`、`Medical Grade`、`Non-Toxic`、`Food Safe`、`Eco-Friendly` 等需要证明的词，**只有产品资料明确支持时才能用**。
- 关键词丰富、准确、自然融入，不机械堆砌。
- 优先使用目标国家买家常用的本土化搜索词和表达，避免生硬翻译。
- 卖点简短、清楚、以转化为导向。每条只表达一个主要购买理由，模块间不重复。
- 重点展示买家关注点、实际需求和使用结果，不要只介绍产品本身。

**Title Case 规则**：标题和 Highlights 使用 Title Case，以下介词/冠词/连词小写：

```
a, an, the, and, or, but, for, of, in, on, at, to, with, from, by
```

上述单词位于开头时可以首字母大写。

## 四、输出内容（9 项）

### 1. 产品定位分析（中文）

简要输出：产品类型 / 目标买家 / 目标国家主要使用场景 / 买家核心需求 / 买家主要痛点 / 下单前主要顾虑 / 产品核心优势 / 建议主推关键词 / 建议避免的风险词或未经证实的表达。

> 必须简洁，不要写成长篇市场报告。

### 2. Title

- 最多 **75 个英文字符**（含空格和标点）
- 符合亚马逊 2026 年 7 月 27 日生效的标题新规（除 Media 外全类目统一 75 字符上限）
- 不为凑满 75 字符加无效词
- 优先保留产品核心名称、重要规格、主要功能、关键使用场景
- **只用关键词表中分配给 Title 的核心词和属性词**，不得把其他模块的词塞进标题
- 不使用品牌名、促销词、特殊符号或重复关键词
- 使用买家自然、常用的搜索表达
- 兼顾关键词覆盖、可读性、移动端展示
- 有变体（颜色/尺寸）时，标题通常不含变体属性，由子 ASIN 变体主题承载

输出后**准确标注实际字符数**：

```
Title: [标题内容]
Character Count: [字符数]
```

### 3. Item Highlights

标题下方展示，搜索结果页与详情页均可见，内容可被搜索。

- 最多 **125 个英文字符**（含空格和标点）
- 符合 2026 年 7 月 27 日新规引入的 Item Highlights 属性
- 补充标题未覆盖的材质、使用场景、适用对象、次要用途
- **只用分配给 Item Highlights 的词**，不重复标题已充分表达的关键词和卖点
- 输出 **4-6 个简短关键词组**，每组 Title Case、介词小写
- 组间用逗号分隔，不写成长句或段落
- 不用空泛、主观或无法证明的词
- 与 Search Terms 的分工：Highlights 前台可见可搜索、需要可读性；ST 后台隐藏、纯关键词、不需要可读性

```
Item Highlights: [内容]
Character Count: [字符数]
```

### 4. 五点描述

5 条简短、高转化的 Bullet Points。每条要求：

- 只展示一个核心卖点，不与其他条重复
- 以简短的 **Title Case 卖点标题**开头
- 建议 1-2 个简短句子
- 先表达买家能获得的实际好处，再说明功能或结构依据
- 自然融入 1-2 个相关关键词，且必须来自分配给五点的长尾词或场景词
- 关键词融入完整句子，满足 §2.3 三条自然度标准
- 5 条之间不得重复主攻同一个关键词
- 结合目标国家买家实际使用场景
- 明确解决买家痛点或下单顾虑
- 不写空泛表达（如「适合多种场景」「提升生活品质」）
- 不添加图片或资料无法证明的功能
- 不重复标题已充分表达的信息
- 不在不同卖点中反复使用相同功能和场景

**排序逻辑**（可按品类灵活调整）：

1. 解决买家最核心的使用问题
2. 关键功能或结构带来的实际好处
3. 材质、稳定性、耐用性或使用体验
4. 安装、清洁、收纳、携带或操作便利性
5. 目标国家常见使用场景、适用空间或兼容范围

**品类排序示例**：

- 电子产品：兼容性/安全认证 → 核心功能 → 材质做工 → 使用便利性 → 适用场景
- 服装：面料/尺码 → 穿着场景 → 工艺细节 → 洗护方式 → 搭配建议
- 家居：解决核心问题 → 功能好处 → 材质耐用性 → 安装便利性 → 适用空间

```
【卖点标题】正文
【卖点标题】正文
【卖点标题】正文
【卖点标题】正文
【卖点标题】正文
```

### 5. 产品描述（两个版本，内容一致）

#### 版本一：HTML 产品描述

- 可直接复制到亚马逊后台的基础 HTML
- **不要用 Markdown 代码框包裹 HTML**
- 仅用 `<p>` `<br>` `<b>` `<ul>` `<li>`
- 不用 CSS、JavaScript、表格、图片、链接、颜色、特殊字体或字号代码
- 2-3 个简短段落，必要时可加简短列表
- 第一段：产品解决的主要问题、目标买家、核心用途
- 第二段：结合目标国家真实使用场景，说明核心功能带来的实际好处
- 第三段：使用便利性、适用空间、包装内容或购买前须知
- HTML 标签不计入建议字符数；正文建议 **600-800 英文字符**（按类目后台限制调整）
- 输出内容中不加解释、备注或复制说明

```
HTML Product Description: [内容]
```

#### 版本二：非 HTML 产品描述

- 与 HTML 版信息一致
- 纯文本，无任何 HTML 标签
- 2-3 个简短段落，段间空一行
- 正文建议 600-800 英文字符
- 适用于不支持 HTML 的后台或其他平台

```
Plain Text Product Description: [内容]
```

#### 两版共同要求

- 使用目标国家自然、本土化语言
- 重点展示买家实际需求与产品价值
- 自然融入分配给描述的**长尾词、场景词、人群词**
- 关键词融入完整句子，满足 §2.3
- 不机械重复标题和五点
- 不逐项堆砌参数
- 不编造品牌故事、认证、性能或售后承诺
- 不使用价格、折扣、配送、赠品或限时促销信息
- 不使用绝对化或无法证明的宣传用语
- 有尺寸、兼容性或使用限制时，客观提醒买家
- 两版的参数、卖点、包装内容和适用场景必须完全一致

### 6. Search Terms

- 一行后台搜索词
- 最多 **250 字节**（英/美站），不含逗号、标点、品牌词或 ASIN
- 只放 Title、Highlights、五点、描述**尚未覆盖**的词
- 同一单词不重复出现
- 补充剩余的同义词、替代方案词、拼写变体
- 使用真实、常用的搜索表达
- 不用无关流量词、竞品品牌或主观促销词
- 不需要重复单复数、大小写或常见拼写变化
- 与 Highlights 分工：ST 后台隐藏、纯补词、不需要可读性

```
Search Terms: [内容]
```

### 7. 图片规范建议（中文）

**主图**：

- 纯白背景（RGB 255,255,255）
- 产品填充画面 ≥85%
- 最短边 ≥1000px 以启用缩放
- 长边不超过 10000px
- 不加文字、水印、Logo（品牌名除外，按类目规则）
- 产品完整可见，不被裁切

**副图（最多 6 张）**，按产品特性选择覆盖：

- 使用场景图：产品在目标国家真实使用环境中的展示
- 尺寸对比图：与常见物品或手的比例参照
- 细节特写图：材质纹理、工艺细节、接口/连接处
- 功能图解图：图示说明核心功能或安装步骤
- 包装内容图：展示买家收到的全部配件和内容物
- 对比/差异化图：与普通产品的差异点可视化

```
图片规范建议：
主图：[建议]
副图1：[建议]
副图2：[建议]
...
```

### 8. A+ Content 可选模块建议（中文）

> 仅在卖家已完成品牌注册（Brand Registry）时输出；未注册则跳过此模块。

推荐模块：

- 品牌故事卡：简短品牌定位 + 核心差异化
- 对比表：与普通产品的关键参数对比（不超过 4 行）
- 使用场景大图：目标国家真实场景的生活方式展示
- 功能图解：核心功能的可视化说明
- FAQ 模块：买家最常问的 3-5 个问题及回答

要求：

- A+ 中的参数、卖点、场景必须与标题、五点、描述完全一致
- 不编造认证、性能或售后承诺
- 图片建议与第 7 节衔接，避免重复拍摄
- 未完成品牌注册则跳过

```
A+ Content 建议：
模块1：[类型] - [内容建议]
模块2：[类型] - [内容建议]
...
```

### 9. 中文翻译

分别提供：Title / Item Highlights / 五点描述 / 产品描述（按非 HTML 版翻译一份，不重复翻译 HTML 版）。

> 仅用于内部审核，不需逐词直译，但必须准确表达原文含义，不得增加原文没有的卖点。
