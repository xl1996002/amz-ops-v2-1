# 图示详情规范：把卖点变成看得见的东西

> 用于 A+ 图、主副图、详情页图示。核心一句：**AI 只出干净底图，文字 / 引线 / 数字 / 图标全部后期叠。**

---

## 一、为什么要"图示化"

三个原因，都跟转化有关：

1. **买家不读长句**。一段 60 词的描述，读完的人远少于看一眼标注图的人。
2. **0 评论时没有社会证明**。图示是唯一能替代"别人说好用"的东西 —— 它把参数变成可数的东西（4 档、45kg、4 色）。
3. **AI 画不准文字和数字**。把文字交给后期叠，图纸只负责画面，两边都不勉强。

---

## 二、六种图示类型（按用途选，一屏只用一种）

| 类型 | 用在哪 | 做法 | 适合什么 | 注意 |
|---|---|---|---|---|
| **A 引线标注** Callout | 主视觉首图、结构图 | 产品居中，引线指向部件，每条跟 3–4 词 | 多个卖点一次讲完 | 端点必须落在真实部件上，不能悬空 |
| **B 图标条** Icon strip | 横图底部、A+ 模块底部 | 4 个线性图标一行，各配 2–3 词 | 重复强调、参数速览 | 整页只用一套图标（同线宽同圆角） |
| **C 数字块** Number block | 高度、承重、容量类 | 超大数字 + 小单位 + 一行说明 | 可量化的核心指标 | **一屏只放一个主数字**，两个互相削弱 |
| **D 分解图** Exploded | 结构复杂的产品 | 部件拉开、标序号 | 说明"里面有什么" | AI 做不了，必须实拍拆分或 3D 渲染 |
| **E 尺寸对比** Size compare | 家具、器械、大件 | 产品与已知物体同基线并列 | 解决"到底多大" | 参照物必须是本地人熟悉的东西 |
| **F 步骤图** Step sequence | 安装、使用流程 | 3 格连续动作，同机位同光 | 降低"装不上"的担心 | AI 做不了连续动作，必须实拍 |

**选择顺序**：能用一个数字说清 → 用 C；要讲多个点 → 用 A；只是补充 → 用 B；讲结构 → 用 D/E/F。

## 三、标注位布局（这是最容易搞错的一步）

**关键前提：标注位必须在出底图时就留好。** 图出来后才发现没地方放字，只能缩小产品或裁掉，整张图就废了。

### 标准布局：产品居中 40%，两侧各 30%

```
┌───────────────────────────────────────────────┐
│ 标注区 30%      产品区 40%      标注区 30%     │
│  ┌───────┐    ┌──────────┐    ┌───────┐      │
│  │ 1     │    │          │    │     4 │      │
│  │ 2     │ ←→ │   产品   │ ←→ │     5 │      │
│  │ 3     │    │          │    │     6 │      │
│  └───────┘    └──────────┘    └───────┘      │
└───────────────────────────────────────────────┘
```

以 970×600 为例：产品落在 **x 300–670**，左侧 0–300、右侧 670–970 全部留空。

- 左侧 3 条标注：左对齐，x≈60
- 右侧 3 条标注：右对齐，x≈910
- 垂直分布：y≈70 / 250 / 470（上中下三档）

**提示词里必须写这句**：`产品占画面正中间，左右两边各留出三分之一的空白`。不写，模型会把产品拍满画面。

### 其他比例的留白

| 尺寸 | 产品占比 | 留白位置 |
|---|---|---|
| 970×600 | 中间 40% 宽 | 左右各 30% |
| 970×300 | 左侧 55–60% | 右侧 40% 整块留白（宽幅不适合两侧夹） |
| 300×300 | 中心 70% | 四周各 15%，不放标注，只配下方文字 |

## 四、排版参数（设计师照此执行，不要各写各的）

| 项 | 规定 | 理由 |
|---|---|---|
| 标签字数 | 每行 ≤16 字符，最多 2 行 | 超过就变成"文案"，标注失去意义 |
| 主标题字号 | 970 宽用 26–30px | 移动端缩到 66% 仍可读 |
| 副文字号 | 18–20px | 小于 18px 手机上糊 |
| 数字块字号 | 主数字 60–90px，单位 20–24px | 数字要能一眼抓住 |
| 引线 | 1.5px 实线 + 3px 圆点端点 | 虚线和箭头显廉价 |
| 引线颜色 | 深灰 #3A3A3A，或品牌深色 | 不用纯黑，避免生硬 |
| 图标 | 线性，2px 线宽，同一套 | 混风格会显得像拼的 |
| 文字安全区 | 距画布边 ≥40px | 避开 A+ 自动裁切 |
| 语言 | **图上只放英文**（目标站语言） | 中文只写在交付文档里 |
| 对齐 | 左侧标注左对齐，右侧右对齐，不居中 | 居中会让两端参差 |

## 五、底图提示词：四句结构

不要写六要素长文，写四句就够：

```
①保持上传图里的〔产品〕完全不变，结构和颜色都不要改。   ← 锁产品
②把它放在〔背景〕前 / 放进〔场景〕。                    ← 给环境
③〔光线描述〕。                                        ← 给光
④横构图，产品占画面正中间，左右两边各留出三分之一的空白。 ← 给构图与留白
```

**两条铁律**：
- 不在提示词里写"加文字""加标注""加箭头" —— 模型会画出乱码。
- 不写精确数值（5cm、45kg、142cm）—— 模型不认数字，写了也没用，还会干扰画面。

### 分工具写法

| 工具 | 负面表述 | 备注 |
|---|---|---|
| ChatGPT / DALL·E | **不支持负面词**。用正向句"画面干净，没有标签和字样" | 写了 `文字, 水印` 反而诱导它画出来 |
| Midjourney | `--no text, watermark, logo --ar 97:60 --iw 1.5` | 垫图时图片链接放最前，`--iw 1.5` 加强参考 |
| SD / ComfyUI | 用 negative prompt 框 + **ControlNet（Canny / Depth）** | 器械类产品必上 ControlNet，否则管件会变形 |
| 即梦 / 可灵 | 参考图强度 0.6–0.8 + 负面词框 | — |

## 六、AI 做不到的六件事（别浪费次数）

1. 同一产品在画面里出现多次且状态不同（多档高度、多配置并排）→ **PS 合成**
2. 精确物理尺寸与比例（5cm 厚、142×92cm 占地）→ **实拍 + 后期标注**
3. 精确数字（89/102/115/129、45kg）→ **后期叠加**
4. 文字（任何语言）→ **后期叠加**
5. 器械类精确管件结构（立柱数量、斜撑角度）→ **垫图 + ControlNet**，仍要人工核对
6. "这一款"而非"这一类"（我们的粉和其他粉）→ **必须垫图**，文字描述色号无效

> 判断口诀：**要"重复"、要"数字"、要"字"的图，一律不用 AI 出成品。**

## 七、交付给设计师的四样东西

做图示详情，不要只丢一堆提示词。四样齐了，设计师才能一次做对：

| # | 物料 | 作用 |
|---|---|---|
| 1 | **标注位示意图**（SVG 或线稿） | 标在哪、引线怎么走、产品放哪，一眼看懂 |
| 2 | **卖点文案表**（英文 + 中文对照） | 每个标注写什么，不超过规定字数 |
| 3 | **排版参数表**（本文件第四节） | 字号、线宽、颜色、安全区统一 |
| 4 | **底图提示词**（四句结构） | 出图的人照抄即可 |

## 八、自检清单

- [ ] 底图左右留白 ≥30%，产品没被拍满
- [ ] 每条标注的引线端点落在真实部件上，没有悬空
- [ ] 一屏只有一个主数字（有第二个就删）
- [ ] 标签每行 ≤16 字符，没有变成句子
- [ ] 图上只有英文，中文在文档里
- [ ] 间距、字号、线宽全套一致（同一套图不能两种风格）
- [ ] 距画布边 ≥40px，移动端预览没有被裁
- [ ] 没有任何 AI 生成的文字残留（放大到 200% 检查一遍）
